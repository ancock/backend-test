# Backend Reservation Test

Lernprojekt für:
HTML → JavaScript → Supabase API → PostgreSQL

## Ablauf
1. Supabase-Projekt erstellen.
2. Tabelle `reservations` anlegen.
3. Project URL und Publishable Key in `script.js` eintragen.
4. Auf GitHub Pages veröffentlichen.
5. Testreservierung absenden.

## Wichtig
Nur den öffentlichen Publishable Key im Browser verwenden. Niemals Secret Keys oder einen `service_role`-Key in den Frontend-Code oder nach GitHub stellen.
